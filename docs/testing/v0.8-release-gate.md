# Ro-Store v0.8 release gate

v0.8 is in development. Do not tag or publish a release until every required
item below is complete on the final source tree.

## Installed software

- [x] Show installed RPM packages and user/system Flatpak applications in one
  searchable view, with version, architecture, source and installed size.
- [x] Keep RPM inventory read-only and mark that it includes system components.
- [x] Use AppStream desktop-app metadata to filter the RPM inventory to
  applications; retain a full-package view and fall back to it when metadata
  is unavailable.
- [ ] Compare an application available from both RPM and Flatpak sources.
  Installed items with matching AppStream and Flatpak IDs now show the other
  installed source and version; catalog-wide comparison remains open.
- [x] Show the resolved RPM dependency plan and explicit removal warning;
  Flatpak removal warns that user data is retained.
- [ ] Show durable update history and useful failure details.
  A read-only DNF5/Flatpak history view shows recent transactions and DNF5
  package/status details; Flatpak history does not record failed operations.
- [ ] Group system update candidates by user-relevant category.

## Flatpak scope deferred from v0.7

- [ ] Test a genuine user-scope application update with an OSTree commit change.
- [ ] In a disposable Fedora 44 VM/user, test interrupted install/uninstall,
  restart recovery, failed reads, network loss, corrupt journal and low disk.
- [ ] Test denied authorization, concurrent Ro-Store instances and RPM/Flatpak
  coordinator lock contention.
- [ ] Add executable backend tests for validation, journal lifecycle and fault
  injection. Keep driver, runtime, codec and extension updates disabled until
  separately qualified.
- [ ] Decide whether system-scope changes and user-scope updates can be enabled
  after their test results are reviewed.

## Release checks

- [x] Local Fedora 44 build, existing Flatpak safety tests and installed-view
  offscreen startup passed on 2026-11-26 for the first inventory changes.
- [ ] CI green on the final v0.8 source tree for x86_64 and aarch64.
- [ ] Test installed view at 400×500, 600×500 and 1000×650, keyboard control,
  KDE light/dark themes and scaling.
- [ ] Validate RPM install/upgrade from the v0.8 release candidate in a
  disposable environment.
- [ ] Bump project/package version only after the release gate passes; then
  tag, publish both RPMs and SHA256SUMS.txt, and verify the GitHub release.
